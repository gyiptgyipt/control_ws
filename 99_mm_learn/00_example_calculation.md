# ထိန်းချုပ်မှုတွက်ချက်မှု ဥပမာ

*ပထမအဆင့် DC motor ၏ အလျင်တုံ့ပြန်မှုကို transfer function နှင့် state-space နှစ်မျိုးဖြင့် တွက်ကြည့်မည်။*

---

## ပုဒ်စာ

ဂီယာဘောက်စ်တပ်ထားသော စက်ရုပ်မော်တာတစ်လုံး၏ အလျင်ဒိုင်နမစ်ကို အောက်ပါပထမအဆင့် transfer function ဖြင့် ခန့်မှန်းထားသည်:

$$G(s)=\frac{\Omega(s)}{V(s)}=\frac{4}{0.5s+1}$$

ဤနေရာတွင် $V$ သည် မော်တာဗို့အား (V)၊ $\Omega$ သည် ထောင့်အလျင် (rad/s) ဖြစ်ပြီး input-output gain သည် $4\;\text{rad/s/V}$ ဖြစ်သည်။ စတင်ချိန်တွင် မော်တာရပ်နေသည်ဟုယူဆပါ။ $t=0$ တွင် 3 V step input ပေးလိုက်လျှင်:

1. အချိန်ကိန်းသေ $\tau$ နှင့် steady-state အလျင် $\omega_{ss}$ ကို ရှာပါ။
2. အလျင်တုံ့ပြန်မှု $\omega(t)$ ကို ရေးပါ။
3. $t=0.5$ s နှင့် $t=1.5$ s တွင် အလျင်ကို တွက်ပါ။
4. 2% settling time ကို ခန့်မှန်းပါ။
5. မော်ဒယ်ကို state-space ပုံစံဖြင့် ရေးပြီး state-space ဖြင့်လည်း အလျင်ကို စစ်ဆေးပါ။

---

## ဖြေရှင်းချက်

### 1. အချိန်ကိန်းသေနှင့် Steady-State အလျင်

ပထမအဆင့် ပုံမှန်ပုံစံမှာ:

$$G(s)=\frac{K}{\tau s+1}$$

ပေးထားသော $G(s)=\frac{4}{0.5s+1}$ နှင့် နှိုင်းယှဉ်လျှင်:

$$K=4\;\text{rad/s/V}, \qquad \tau=0.5\;\text{s}$$

Step input ၏ အရွယ်အစား $V_0=3$ V ဖြစ်သဖြင့် နောက်ဆုံးတည်ငြိမ်အလျင်မှာ:

$$\omega_{ss}=K V_0=4\times 3=12\;\text{rad/s}$$

### 2. အလျင်တုံ့ပြန်မှု

အရွယ်အစား $V_0$ ရှိ step input အတွက် ပထမအဆင့်တုံ့ပြန်မှုမှာ:

$$\omega(t)=K V_0\left(1-e^{-t/\tau}\right), \quad t\geq 0$$

တန်ဖိုးများ အစားထိုးလျှင်:

$$\boxed{\omega(t)=12\left(1-e^{-2t}\right)\;\text{rad/s}}$$

စစ်ဆေးရန်, $t=0$ တွင် $\omega(0)=0$ ဖြစ်ပြီး အချိန်ကြာလာသည်နှင့် $\omega(t)$ သည် $12\;\text{rad/s}$ သို့ နီးကပ်သွားသည်။

### 3. သတ်မှတ်ထားသော အချိန်များတွင် အလျင်

**$t=0.5$ s** (အချိန်ကိန်းသေတစ်ခု):

$$\omega(0.5)=12(1-e^{-2(0.5)})=12(1-e^{-1})$$

$$\omega(0.5)\approx 12(1-0.3679)=\boxed{7.59\;\text{rad/s}}$$

အချိန်ကိန်းသေတစ်ခုတွင် step တုံ့ပြန်မှုသည် နောက်ဆုံးတန်ဖိုး၏ ခန့်မှန်းခြေ 63.2% ကို ရောက်သည်။ $12\times0.632\approx7.58$ ဖြစ်သဖြင့် ရလဒ်နှင့် ကိုက်ညီသည်။

**$t=1.5$ s** (အချိန်ကိန်းသေသုံးခု):

$$\omega(1.5)=12(1-e^{-2(1.5)})=12(1-e^{-3})$$

$$\omega(1.5)\approx 12(1-0.0498)=\boxed{11.40\;\text{rad/s}}$$

ဤအချိန်တွင် နောက်ဆုံးတန်ဖိုး၏ 95% ခန့်ကို ရောက်နေသည်။

### 4. 2% Settling Time

ပထမအဆင့်စနစ်အတွက် 2% settling time ကို:

$$t_s\approx4\tau=4(0.5)=\boxed{2.0\;\text{s}}$$

ဆိုလိုသည်မှာ $t\approx2$ s နောက်ပိုင်းတွင် အလျင်သည် $12\;\text{rad/s}$ ၏ 2% အတွင်း၊ ခန့်မှန်းအားဖြင့် $11.76$ မှ $12.24\;\text{rad/s}$ အတွင်းတွင် ရှိနေမည်။

### 5. State-Space ပုံစံနှင့် အတည်ပြုခြင်း

Transfer function ကို အောက်ပါအတိုင်း ပြန်ရေးပါ:

$$G(s)=\frac{4}{0.5s+1}=\frac{8}{s+2}$$

အောက်ပါ state ကို ရွေးပါ:

$$\dot{x}=-2x+V, \qquad \omega=8x$$

ထို့ကြောင့်:

$$A=[-2], \quad B=[1], \quad C=[8], \quad D=[0]$$

ကနဦးအခြေအနေ $x(0)=0$ ဖြစ်ပြီး $V=3$ V အဝင်ကို အဆက်မပြတ်ပေးထားလျှင် state equation ၏ အဖြေမှာ:

$$x(t)=\frac{V}{2}\left(1-e^{-2t}\right)=1.5\left(1-e^{-2t}\right)$$

အထွက်မှာ:

$$\omega(t)=Cx(t)=8\times1.5\left(1-e^{-2t}\right)=12\left(1-e^{-2t}\right)\;\text{rad/s}$$

Transfer function ဖြင့် ရရှိသော အဖြေနှင့် အတိအကျ တူညီသည်။

## အဖြေ အကျဉ်းချုပ်

| ပမာဏ | အဖြေ |
|---|---:|
| Gain $K$ | $4\;\text{rad/s/V}$ |
| အချိန်ကိန်းသေ $\tau$ | $0.5\;\text{s}$ |
| နောက်ဆုံးတည်ငြိမ်အလျင် | $12\;\text{rad/s}$ |
| $t=0.5$ s ရှိ အလျင် | $7.59\;\text{rad/s}$ |
| $t=1.5$ s ရှိ အလျင် | $11.40\;\text{rad/s}$ |
| 2% settling time | ခန့်မှန်းခြေ $2.0\;\text{s}$ |
| State-space matrix များ | $A=[-2], B=[1], C=[8], D=[0]$ |

**ယူဆချက်:** မော်တာ saturation၊ load ပြောင်းလဲမှုနှင့် friction nonlinearities တို့ကို မထည့်ထားသော ရိုးရှင်းမော်ဒယ်ဖြစ်သည်။ Hardware ပေါ်တွင် controller သုံးမည်ဆိုပါက တိုင်းတာထားသော မော်တာဒေတာဖြင့် မော်ဒယ်နှင့် တွက်ချက်မှုကို အတည်ပြုသင့်သည်။
